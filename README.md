# feco-exam — треки подготовки к ЕГЭ/ОГЭ

Два входа в один продукт:

**Для учеников и родителей:** самоподготовка с качеством разбора уровня репетитора за цену ниже одного занятия (490 ₽ за трек темы навсегда; подписка на все треки — 299 ₽/мес). «Не замена репетитору, а настоящая самоподготовка».

**Для репетиторов:** помощник-диагност — находит слабые места и слепые зоны ученика до занятия: карта ловушек по ошибкам диагностики, данные тренажёра (тип задач, серия, рекорд), готовность к теме в % для родителя. Плюс сборка трека по теме репетитора из его материалов (15–45 тыс. ₽).

## Первый трек (готов)

**ЕГЭ математика (профиль): задачи на проценты**
- 🧪 Диагностика: 5 задач, проверка с разбором каждой ловушки (какие ловушки сработали — видно по пунктам)
- 📘 Разбор: методика «3 шага» + шпаргалка множителей + таблица типичных ошибок
- ♾️ Тренажёр: генераторы меняют числа — «выучить варианты» невозможно; серия и рекорд сохраняются
- 🎓 Мини-экзамен: готовность к теме в процентах (порог 80%)
- Задания — собственные аналоги типов открытого банка ФИПИ (не КИМы)

## Технически

- Один самодостаточный HTML-файл (`index.html`), без зависимостей — работает офлайн и на GitHub Pages
- Прогресс и рекорды — в localStorage браузера ученика
- Новые темы добавляются по тому же паттерну: диагностика → разбор → генератор → экзамен
