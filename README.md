# feco-exam — треки подготовки к ЕГЭ/ОГЭ

Продукт для учеников и родителей: интерактивные треки по темам ЕГЭ/ОГЭ — качество разбора уровня репетитора, цена ниже одного занятия.

**Позиционирование:** не «замена репетитору», а «настоящая самоподготовка»: диагностика ловушек → методика разбора → тренажёр с бесконечными вариантами → экзамен-контроль готовности.

## Первый трек (готов)

**ЕГЭ математика (профиль): задачи на проценты**
- 🧪 Диагностика: 5 задач, проверка с разбором каждой ловушки
- 📘 Разбор: методика «3 шага» + шпаргалка множителей + таблица типичных ошибок
- ♾️ Тренажёр: генераторы меняют числа — «выучить варианты» невозможно; серия и рекорд сохраняются
- 🎓 Мини-экзамен: готовность к теме в процентах (порог 80%)
- Задания — собственные аналоги типов открытого банка ФИПИ (не КИМы)

## Технически

- Один самодостаточный HTML-файл (`index.html`), без зависимостей — работает офлайн и на GitHub Pages
- Прогресс и рекорды — в localStorage браузера ученика
- Новые темы добавляются по тому же паттерну: диагностика → разбор → генератор → экзамен
