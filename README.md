# ФЕКО ЕГЭ/ОГЭ — настоящая самоподготовка

Интерактивные тренажёры подготовки к ЕГЭ/ОГЭ. Прод: **https://efefelov.github.io/feco-exam/**

## Что внутри

- **Каталог предметов** (`index.html`): онбординг «3 шага», каталог, прайс, активация кода, вкладка «Репетитору».
- **Треки предметов** (каждый — самодостаточный HTML):
  - `ege-math-prof.html` — ЕГЭ математика (профиль), задания 1–14 ч.1;
  - `ege-math-base.html` — ЕГЭ математика (база);
  - `ege-rus.html` — ЕГЭ русский язык (орфография/грамматика);
  - `ege-inform.html` — ЕГЭ информатика;
  - `ege-fiz.html` — ЕГЭ физика (формулы ч.1);
  - `oge-math.html` — ОГЭ математика ч.1.
- В каждом треке: 🧪 диагностика → 📘 разбор → ♾️ тренажёр с генераторами → 🎓 мини-экзамен с «Готовностью %» → 📊 прогресс и отчёт для репетитора.

## Механики удержания

Серия дней (стрик) с заморозкой · задача дня (одинаковая у всех в этот день) · золотые задачи (×2 к серии) · ранги и бейджи · экзамен-режим с таймером · напоминания от TG-бота.

## Валидация и верификация

- Готовность — взвешенная по типам (не среднее); показывается только при достаточной выборке, с указанием уверенности оценки.
- Анти-чит по времени ответа; «выучить варианты» невозможно — числа меняются.
- Мини-экзамен с таймером — верифицированный замер с большим весом.
- Отчёт для репетитора: карта ловушек + время на задачи (данные трудно подделать).

## Продажа

- **TG-бот** (Cloudflare Worker, сборщик `запуск/сборка_бота.py`): задачи в чате, оплата Telegram Stars (560 ⭐ трек / 280 ⭐/мес всё), код активации с контрольной суммой.
- **VK**: сообщество + мини-апп (iframe сайта), продажа ручными кодами.
- Коды: `MAT-XXXXXXXX` — один предмет навсегда, `ALL-XXXXXXXX` — всё на 30 дней. Алгоритм чексуммы одинаков на сайте и в боте (проверяется офлайн, без сервера).

**Цены** (по конкурентному анализу): трек предмета 990 ₽ разово (репетитор: 1 500–2 500 ₽/час), все предметы 490 ₽/мес (онлайн-школы: 4 000–10 000 ₽/мес).

## Правовая линия

Задания — **собственные аналоги типов открытого банка ФИПИ** (демоверсии, кодификаторы, открытый банк). Реальные КИМы текущего года не используются — это написано в UI. В репозитории нет паролей, токенов и личных данных (бот-воркер и тактика — в не-gitness папках `bot/` и `запуск/`).

## Обновление контента

Генераторы живут в треках; бот собирается из них: `python запуск/сборка_бота.py` → вставить `bot/cf-exam-bot-worker.js` в воркер. Треки пересобираются из шаблона `ege-math-prof.html` скриптом `запуск/сборка_треков.py`. Тест генераторов: `node`-прогон 1000 вариантов на тип (валидность: ≥2 уникальных варианта, корректный индекс ответа).
