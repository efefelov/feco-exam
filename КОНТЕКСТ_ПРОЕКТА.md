## Позиционирование — двойная аудитория в одном файле

1. **Ученики и родители:** самоподготовка с качеством разбора уровня репетитора — **трек одной темы 490 ₽ разово (в разработке оплата), подписка на все треки 299 ₽/мес** (для сравнения: занятие репетитора 2 000–3 000 ₽). «Не замена репетитору, а настоящая самоподготовка».
2. **Репетиторам:** **помощник-диагност** — находит слабые места и слепые зоны ученика ДО занятия: карта ловушек по ошибкам диагностики (каждая ловушка подписана: «складывает проценты вместо перемножения», «путает базу»…), данные тренажёра (тип задач, серия, рекорд), готовность к теме в % для родителя. Плюс сборка трека по теме репетитора из его материалов — **15 000–25 000 ₽ за тему, 25 000–45 000 ₽ за программу, сопровождение от 5 000 ₽/мес**.

## Первый трек (готов): «ЕГЭ математика (профиль): задачи на проценты»

Паттерн, который переносится на любую тему:

1. 🧪 **Диагностика** — 5 проверенных задач с вариантами; проверка показывает, какие конкретные ловушки сработали
2. 📘 **Разбор** — методика «3 шага» («переведи проценты в множитель», «от ЧЕГО проценты», «последовательные изменения перемножай») + шпаргалка множителей + таблица «тип → схема → ловушка»
3. ♾️ **Тренажёр** — **генераторы бесконечных вариантов**: числа меняются при каждом прохождении («выучить варианты» невозможно), решение с подстановкой конкретных чисел пользователя, серия/рекорд в localStorage
4. 🎓 **Мини-экзамен** — 5 сгенерированных задач → «Готовность к теме: X%» (порог зачёта 80%)
5. 💼 **Репетитору** — помощник-диагност + как встроить в практику + прайс сборки

Генераторы темы «проценты»: genA (изменение цены), genB (два изменения подряд — классическая ловушка «+20% и −20% = без изменений»), genC (вклад с капитализацией vs простые проценты).

## Технические грабли (решены, не повторять)

- **Генераторы:** при некоторых комбинациях ловушки совпадают с верным ответом (пример: p=50 «вниз», X*p/100 = новый ответ) → нужен расширенный пул кандидатов + dedupe + фильтр v>0; проверять 1000 прогонов `t.o.length===4 && new Set(t.o).size===4 && 0<=t.c<=3`
- **data-c:** в разметке тренажёра потерялся атрибут data-c → проверка сломалась «тихо»; всегда добавлять
- Проверка синтаксиса: извлечь `<script>` → `node --check`; затем браузерный прогон всех вкладок
- Кириллица в JSON payload curl API → писать payload в файл через python, `--data-binary @file`
